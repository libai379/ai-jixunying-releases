# AI集训营

把国内外的大模型拉进一个应用：单聊像豆包，群聊里多个 AI 能互相 @、互相纠错；还能让 AI 读写电脑上的文件、写代码、画图、做视频、接微信。
Windows 桌面端 + 安卓端，两边都能单独用；手机配对电脑后，在任何地方（不用同一个 Wi-Fi）都能遥控电脑上的 AI集训营。
不需要自己的服务器：手机和电脑能直连就直连，连不上就经免费的公共中转，内容端到端加密，中转只看得到乱码。聊天记录、附件、API Key 都只存在你自己的设备上。

这个仓库只放安装包，不放代码。

- 电脑整包：AI-Jixunying-版本-日期-windows-update.zip，给程序里「检查更新」用的，一般不用自己下载。

## 功能

### 对话和群聊

- 单聊和群聊；群聊默认「独立作答」，每个 AI 各答各的、互相看不到，避免跟风附和；答完可以互相 @ 补充或纠错
- 点名：不用 @，直接喊名字（「阿麦，画一张图」「让阿德来算一下」）就只有被叫到的回答；只是提到名字（「阿麦说得不对，大家怎么看」）大家照常回答
- 立场档案：群聊里有答案的问题，记下每位成员一开始怎么说、后来谁改了口、为什么改（被说服、跟风、迎合你、自己查证）；你标一下谁对，每位成员一张卡：首答准确率、坚持度、跟风、被带偏、被纠正——就是当初立项想量化的「AI 会不会被带偏」
- 会审模式（群聊里打开）：先各自独立回答，再匿名互评、排名次，最后由中立的主席写最终答案，写清一开始有几种说法、谁对谁错、少数派意见——借鉴 Karpathy 的 llm-council 和「讨论越久越容易被带偏」的研究，只讨论一轮
- 中立裁判和 AI 核实：立场由单独的裁判模型来记（默认 DeepSeek-V4.1-Flash，可以换），给裁判看的聊天可以隐去成员名字（成员甲 / 乙 / 丙）；开新议题后裁判会自己联网查一次谁对，你没标的题可以按它的结论算，你标的永远优先
- 每位成员可以选「默认 / 快速 / 深度」：快速少想快答，深度想透再答（各家模型的切换参数不一样，查不到的平台不让选）
- 每个 AI 知道自己是谁、背后是什么模型，也知道群里还有谁、用户是谁；知道今天几号、星期几、农历节气、放不放假，聊天里每句话标着几点说的
- 说话规矩：回答只说结论、有主见不随声附和；不知道就说不知道；时效性问题、史实、出处、具体数字先联网查再答，并标出处
- 联网搜索：默认用模型自带的——智谱、千问用平台官方内置搜索，DeepSeek 用 DeepSeek 官方搜索，小米、MiniMax 借用 DeepSeek 的；也可以换必应、博查、Tavily、Brave 等
- 读链接：贴抖音、小红书、快手、微博、B 站的链接，读出作品文字，图文作品里的图下载给 AI 看，视频能「听」（最长 10 分钟）
- 附件：图片给能看图的模型；PDF、Word、Excel、PPT、代码、文本自动转成文字；视频取画面加听写；音频先听写，千问全模态直接听原声
- 聊天里的视频直接在软件里放，大图能左右翻、放大看细节
- 后台出错提示：压缩聊天、记长期记忆、点名、立场档案、AI 核实在后台出错时会告诉你哪里坏了、去哪改

### 让 AI 干活

- 做 Word、Excel、PPT：说「做成 Word」「整理成表格发我」「做个汇报 PPT」，成员直接交给你一个 .docx / .xlsx / .pptx 文件；Word 有通用、正式、公文三套排版，Excel 的数字、金额、日期能直接计算，自动冻结表头、加筛选、算合计；PPT 有五套配色，封面、目录、章节页自动排，讲稿放进演讲者备注；每条回答也能「存成 Word」
- 电脑上的文件：AI 能找文件、读文件、新建和修改文件（改前备份，能看差异、能撤销）、跑命令；能把电脑上的文件直接发给你（微信里说「把桌面上的《XX》发给我」也行）。私钥、密码库、.env 这类一律不发
- 画图：千问图像 / 通义万相、豆包 Seedream、混元生图、文心 iRAG、硅基流动、魔搭、OpenAI gpt-image 等；不用专门设置，配好的服务商里能画的自动用上（画质优先：千问图像排第一，画里的中文字写得准；某家余额用完自动换下一家）；能带参考图画「同一个人换个姿势、换个场景」；实测手脚常画畸形的模型不自动用，点名才用
- P 图：发一张图说要改哪里（去掉字、水印、笔迹，打码，裁剪，转方向，改字，标注，调亮度，拼图），程序直接改原图的像素，没动到的地方一个像素都不变，不花钱；复杂背景上去掉一样东西、加一样东西，AI 圈出来交给改图模型补画
- 做视频：说「做一段……的视频」，支持首帧 / 首尾帧、参考图、参考视频、视频编辑、视频延长；做好后 AI 自己先看一遍成片再交给你；也有「直接做视频」按钮，不经过 AI
- 配音和朗读：说「用语音读一下这段话」，AI 读成音频文件发你；每条回答下面有小喇叭能读出来
- AI 自己挑模型、换着试：画图、补画、做视频、配音不满意会换一个模型再试，你只收到最好的那个；再试的花钱上限能设（默认 2 元）

### 记忆和资料

- 记忆：聊得太长时记录员把前面压成摘要（群里共用一份）；关于你的长期记忆所有对话、所有成员都能用，能看能改，每条能点回原话；手机电脑双向同步
- 两种记忆：完整记忆整份带上；联想记忆按这会儿聊的挑相关的带上，常用的往前排。输入框旁随时切，也能「换一种记忆再答一次」放在一起比
- 本地文档：电脑和手机各自给设备里的文档建索引，在聊天里问「我那份合同里写的付款日期是哪天」，AI 会自己搜、自己读
- 按意思搜：聊天记录、我的文档换个说法也能搜到（问「保证金怎么退」能找到讲「押金」的那次聊天），默认关，打开前先估算花多少钱
- 个性化：自定义指令，所有对话都照着做

### 语音

- 听写：输入框旁的话筒，说完认出来的字填进输入框，看一眼再发
- 读出来：支持小米、MiniMax、智谱、千问的语音模型，能选音色、语速，能设回答完自动读

### 微信助理

- 扫码绑定（腾讯官方 ClawBot 接口，和 WorkBuddy 的微信助理一样），在微信里发文字、图片、文件、视频、语音给它，AI 回答；做的图、文件、视频直接发回微信，视频能在微信里直接播
- 一台电脑能挂好几个微信，每个能起名字
- 电脑和手机都能接：电脑开着就电脑答，电脑关了由手机接着答（手机自动用电脑的同一个绑定，不重复回答，各有开关）
- 连着发几条会攒在一起按最后一条答；引用以前的消息也能找回原文

### Code 栏（电脑端，手机连电脑也能用）

- 选一个项目文件夹，用一句话让 AI 读代码、改文件、跑命令；每一步写清读了什么、改了什么（红绿差异）、跑了什么命令；改过的文件能逐个接受、拒绝或全部撤销
- 权限四档：手动、接受编辑、计划、自动，和 Claude Code 一样；工作区外的先问
- 谁来干活：自己加的模型，或者你电脑上装的 Claude Code、Codex、Gemini CLI；Claude Code 能当总指挥，给开发 / 审查 / 测试各派一个 AI，「一条龙」模板让程序自动转
- 后台命令、内置终端、无界面浏览器预览、提交推送到 GitHub
- 项目文档只记一份 AGENTS.md，各家 AI 读不到的由程序交给它；做事中途能插话、随时停
- 手机遥控电脑时也能新建 Code 会话、发任务、批准或拒绝每一步

### 狼人杀

- 法官是程序，每个 AI 用自己的模型、自己想、自己说；两种玩法：「我当主持人」全是 AI 打、你看得到所有身份；或者你自己上桌一起玩

### 手机和电脑

- 手机扫电脑上的二维码配对；一台电脑能连好几台手机
- 手机能直连电脑就直连（WebRTC，和视频通话一样的办法），聊天不经过任何服务器；连不上自动经公共中转
- 模型服务、成员、记忆、账本、微信对话自动同步；手机能借电脑上的本地模型用，能把整个对话「发给电脑」
- 手机单独也完整可用；电脑掉线自动切回本机并提示
- 电脑点叉只藏到托盘，微信助理、手机遥控、后台命令照常跑

### 本地模型

- 接 Ollama、LM Studio；小模型能开「精简模式」，设定短、只在指定的工作区文件夹里写文件（程序拦，不靠模型自觉）
- 「测上下文」：程序一档一档加长聊天，测出这个模型扛得住多长，显示用了百分之几

### 服务商和花费

- 服务商预设：DeepSeek、智谱、Kimi、MiniMax、千问、通义百炼、豆包、小米 MiMo、腾讯混元 / TokenHub、百度千帆、阶跃、美团 LongCat、硅基流动、魔搭、OpenAI、Claude、Gemini、Grok、Mistral、Groq、OpenRouter、Ollama 等，都按 OpenAI 兼容协议接入；也能用 ChatGPT 账号登录直接用订阅
- 花费：每次调用模型、每张图都记账，按官方价格算钱（单价能自己改），按成员、模型、用途、天看；能直接查 DeepSeek、Kimi、硅基流动等平台的余额，查不了的能手动填
- 账号：本机密钥账号（口令加密的备份码），或者用 GitHub 登录

### 上手

- 新手引导在真界面上讲，新用户必看三章加十几章进阶，每次更新先讲这一版新加了什么
- 「功能介绍」页：所有功能列在一页，能搜，点「带我去」就跳到那里圈出来讲
- 界面是液态玻璃 + 弹簧动画，能换自己的图片、纯色或渐变当背景，字跟着背景深浅自动变色

## 技术

Kotlin 多平台 + Compose Multiplatform，桌面和安卓共用界面和引擎代码。手机和电脑优先 WebRTC 直连；连不上走 MQTT 公共中转（EMQX、HiveMQ）。内容 AES-256-GCM 端到端加密。
